USO

1. Mantén todos los archivos en la misma carpeta.
2. Abre derivacion_LL_completo_tensorial_MAIN.ipynb.
3. Cambia únicamente:

       m_input = 2

4. Ejecuta las celdas de arriba hacia abajo.

INTERPRETACIÓN DEL INPUT
------------------------
m_input es el ORDEN MÁXIMO incluido en la teoría.

    m = 0  -> L = c0 L0
    m = 1  -> L = c0 L0 + c1 L1
    m = 2  -> L = c0 L0 + c1 L1 + c2 L2
    m = 3  -> L = c0 L0 + c1 L1 + c2 L2 + c3 L3
    etc.

Los coeficientes c0, c1, ..., cm se crean automáticamente.

PARA m = 2
----------
    L0 = 1/(16*pi)

    L1 = R/(16*pi)

    L2 = [R_abcd R^abcd - 4 R_ab R^ab + R^2]/(16*pi)

    L = c0 L0 + c1 L1 + c2 L2

CADENA DE CÁLCULO
-----------------
    Construir L0, ..., Lm
    -> construir L total
    -> derivar cada P_(k)^abcd
    -> sumar P^abcd = sum c_k P_(k)^abcd
    -> derivada métrica total
    -> Rcal_ab total
    -> derivada de Lie por dos rutas
    -> variar sqrt(-g)L
    -> Palatini
    -> sustituir delta Gamma
    -> primera IBP
    -> segunda IBP
    -> término de borde
    -> E_ab

RESULTADO IMPORTANTE
--------------------
Cada término de Lovelock satisface

    nabla_a P_(k)^abcd = 0.

Por linealidad,

    nabla_a P^abcd = 0

para el P total. Por ello,

    -2 nabla^m nabla^n P_amnb = 0.

El notebook también genera una forma explícita de E^i_j que NO contiene
abreviaturas L_k. Para m=2 aparecen directamente los sectores:
    - cosmológico,
    - Einstein--Hilbert,
    - Gauss--Bonnet.

VALIDACIÓN
----------
La cadena completa fue probada para:
    m = 0, 1, 2, 3 y 5.

En todos los casos, todas las verificaciones automáticas dieron cero.
