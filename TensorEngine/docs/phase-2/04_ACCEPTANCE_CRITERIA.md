# Fase 2.4 — Criterios de aceptación

## Índices y transformaciones

- [x] Renombrado simultáneo y seguro.
- [x] Canonización idempotente de índices mudos.
- [x] Igualdad de formas alfa-equivalentes.
- [x] Producto tensorial sin contracciones accidentales.
- [x] Sustitución con preservación de índices libres.
- [x] Simetrización y antisimetrización normalizadas.

## Canonización

- [x] Simetría de la métrica.
- [x] Antisimetría de ambos pares de Riemann.
- [x] Intercambio de pares de Riemann.
- [x] Combinación de términos iguales con coeficientes racionales.
- [x] Canonización completa idempotente.

## Métrica y dimensión

- [x] Subida y bajada explícita de índices.
- [x] Contracciones directas con la métrica.
- [x] Contracciones con el delta de Kronecker.
- [x] Trazas métricas y `delta^a_a = D`.

## Backend

- [x] Interfaz abstracta independiente de implementación.
- [x] Capacidades soportadas declaradas.
- [x] Capacidades ausentes producen un error controlado.
- [x] Bianchi multitémino conserva residual `undetermined`.
