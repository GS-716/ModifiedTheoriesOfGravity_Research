# Fase 6.4 — Criterios de aceptación

## Difeomorfismos

- [x] Variación de `g^{ab}` simétrica y con el signo de la métrica inversa.
- [x] Variación `delta_xi phi=xi^a nabla_a phi`.
- [x] Evaluación de los potenciales métrico y escalar de fase 5.

## Noether–Wald

- [x] Corriente `J_xi^a=Theta_xi^a-xi^a L`.
- [x] Término fuera de capa `2E^a_b xi^b`.
- [x] Identidad `2 nabla^a E_ab+E_phi nabla_b phi`.
- [x] Potencial antisimétrico `Q_xi^{ab}`.
- [x] Divergencia y residual de la descomposición de la corriente.
- [x] Resultado completo serializable como JSON.
- [x] Capacidades declaradas en el contrato de backend.

## Referencias y validación

- [x] Lagrangiano constante: identidad y descomposición estructurales exactas.
- [x] Einstein–Hilbert: potencial de Komar.
- [x] Sector escalar de primer orden sin carga de Wald propia.
- [x] Nueve comprobaciones reales Wolfram/xAct aprobadas.
- [x] Caso no minimal `f(phi)R` usado para fijar el signo del término `nabla P`.
- [x] Cero verificaciones externas fallidas o indeterminadas.
- [x] Suite completa compatible con las fases 0 a 5.

No pertenecen todavía a esta fase la integración sobre una superficie concreta,
la elección de horizonte, la entropía de Wald, las cargas asintóticas ni las
ambigüedades fijadas por condiciones de contorno específicas.
