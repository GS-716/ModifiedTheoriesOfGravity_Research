# Criterios de aceptación de fase 8

La fase queda cerrada cuando:

- existe un informe único con política determinista de estados;
- los objetos obligatorios se validan por firma, simetría y reconstrucción;
- una corrupción deliberada de frontera o símbolos produce `failed`;
- los residuales no decidibles permanecen `undetermined` y serializables;
- la proyección de componentes se recalcula, no se acepta por confianza;
- las comprobaciones Wolfram se integran con espacio de nombres propio;
- el modelo escalar–tensor general completa la derivación sin errores de higiene
  de índices;
- toda la suite Python y las regresiones Wolfram anteriores permanecen limpias.

La exportación del manifiesto completo, LaTeX y artefactos de presentación
corresponde a la etapa `export`, posterior a esta fase.
